      How passwords work

      After each game, the stats screen shows a password with your record: wins and losses (up to 255 each), your current win streak, and which teams you've beaten. To load it, start a game, choose Yes to enter initials, type your initials, then type the password.

      NBA Jam on Super Nintendo, Game Boy and Game Gear uses one 14-character scheme: a password from one works on the others. It remembers each team you've beaten. Tournament Edition on Game Boy and Game Gear uses a 10-character scheme of its own, shared by both. It plays the teams in a fixed order and only remembers how far along you are. (Tournament Edition on the other systems saves records instead of using passwords.)

      A password only works with the initials it was made for, because the initials are part of its key. If it's rejected, the game says No record and starts you from scratch.
