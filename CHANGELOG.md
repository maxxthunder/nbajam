# Changelog

Changes to the [password checker](https://maxxthunder.github.io/nbajam/) and [secret codes page](https://maxxthunder.github.io/nbajam/codes.html). The version is shown at the bottom of the page.

## 1.2.1 (2026-10-23)
- Secret codes page: the arcade games' preset records (13 on the original, 7 more on Tournament Edition), all tested;
  the arcade prototypes' big heads. Notes: no other hidden inputs in either arcade game, a pause-quit on the
  Tournament Edition handhelds, the Tournament Edition prototype's location-test message, and corrected Super
  Nintendo and Sega CD input notes.

## 1.2.0 (2026-10-23)
- Desktop layout: on the secret codes page each row of version tabs has a small logo beside it, the page is wider,
  and the tabs and search stay at the top while scrolling; the password checker shows the password and the record
  side by side. Phones look the same as before.

## 1.1.9 (2026-10-23)
- Secret codes page: match-up power-ups for the original NBA Jam on Super Nintendo and Genesis (all seven tested;
  two published slips corrected) and the Sega CD's own seven button sequences (all new). The Jaguar's random secret
  character for 27-team records is now tested.

## 1.1.8 (2026-10-23)
- Secret codes page: two hidden Jaguar codes, found by scanning every keypad check: * + # + Option after a soft
  reset clears the cartridge memory, and a 27-team record can hand players a random secret character. The PC
  keyboard has no hidden codes.

## 1.1.7 (2026-10-23)
- Secret codes page: the PC's super speed measured in play (no effect; fixing one check makes it work), and the
  unused match-up code confirmed in play on Genesis and 32X (every other code reaches its player, this one doesn't).

## 1.1.6 (2026-10-23)
- Secret codes page: which arcade revisions have each match-up code (rev 2.00 has all but computer assistance off;
  rev 1.00 only defense and big heads, with no messages), tested in MAME.

## 1.1.5 (2026-10-21)
- Secret codes page: the PC's shot percentage and big body codes checked in play (they set their flags but change
  nothing); what the Jaguar's CD-ROM mode and Doom mode do.

## 1.1.4 (2026-10-21)
- Secret codes page: match-up codes for Tournament Edition on PlayStation (19), Saturn (19) and Jaguar (24), all
  tested. None are new.

## 1.1.3 (2026-10-20)
- Secret codes page: match-up codes for the original arcade game (the published intercept code needs 5 presses
  first, and there's no offense power-up), what the tank game's reward gives, and the PC's 19 match-up codes (8
  new; shot percentage, big body and super speed do nothing). The PlayStation END record is no longer marked new.

## 1.1.2 (2026-10-20)
- Secret codes page: match-up power-ups for NBA Jam on Game Boy and Game Gear, with the exact press counts (the
  published juice mode codes are one press short); the Saturn secret players do need L + R held on each letter.

## 1.1.1 (2026-10-18)
- Password checker: clearer error messages, and a Tournament Edition record past 27 teams shows as all 27 beaten.
- Secret codes page: a clip that fails to play no longer leaves its button highlighted.
- README rewritten to cover both pages and the research; MIT license added.

## 1.1.0 (2026-10-18)
- Password checker: NBA Jam passwords from Game Boy and Game Gear, and Tournament Edition passwords from Game Boy and
  Game Gear.
- Secret codes page: match-up codes for Tournament Edition on Super Nintendo, Genesis and 32X, read from each game's
  table (12 of the 32X's are new, and all three have an unused code); hidden title-menu codes and preset records;
  playable announcer clips for the Genesis speech codes; the arcade logos; shorter notes.

## 1.0.0 (2026-10-17)
First release.
- Check a Super Nintendo password against its initials, the way the game does.
- Shows wins, losses, percentage, win streak and which of the 27 teams are beaten.
- [Secret codes page](https://maxxthunder.github.io/nbajam/codes.html): every secret character and hidden code for
  Super Nintendo, Genesis, arcade, Game Boy, Game Gear, Sega CD, and Tournament Edition on arcade, Super Nintendo,
  Genesis, 32X, Saturn, PlayStation, PC, Jaguar, Game Boy and Game Gear, with portraits and the ones no published list
  had marked ★ New.
